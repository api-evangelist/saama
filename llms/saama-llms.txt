# Saama

> Saama (Saama Technologies, Inc.) builds AI-powered clinical analytics software for

## Agent-facing status (measured 2026-08-26)

Saama publishes **no public API**. There is no developer portal, no API reference, no
machine-readable specification of any kind, and no agent surface. An agent cannot call Saama.

- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, WSDL or Protobuf contract was found on any host.
- No MCP server, no A2A agent card, no llms.txt (https://www.saama.com/llms.txt returns 404).
- `developer.saama.com`, `docs.saama.com`, `api.saama.com` and `apidocs.saama.com` do not resolve.
- Every `/.well-known/*` path on www.saama.com returns the WordPress HTML homepage shell, not a
  document. Do not treat those 200s as served manifests.
- `https://www.saama.com/api/`, `/developers/` and `/docs/` all HTTP **301 to the homepage**. So do
  `/sla/`, `/changelog/`, `/release-notes/` and `/status/`. There is no reference material behind
  any conventional path, and the 103-URL page sitemap names none.
- No MCP server, remote or local: `mcp.saama.com` and `agents.saama.com` do not resolve, and no
  Saama-published MCP package exists on npm or PyPI.
- No first-party SDK on any registry. Seven Saama-owned or Saama-derived GitHub orgs were checked
  (`saamaresearch`, `comprehend`, `SaamaInc`, `Saama-Technologies`, `SaamaAnalytics`,
  `Saama-CodeBase`, `saama-ites`); five hold zero public repos and the other two hold only forks.
  `comprehend` is the residue of Comprehend Systems, the clinical-analytics company Saama acquired
  - comprehend.com no longer resolves.
- The only technical channel is https://support.saama.com/, which 302s to
  `https://support.saama.com/support/login` (Freshdesk). Documentation, if it exists, is
  customer-only.
- A customer-facing API almost certainly exists and Saama says so in exactly one sentence: the
  Smart Medical Coding page advertises "Inbound/outbound APIs, EDC connectors, and token-based
  authentication". Saama's 2025 announcement says its Clinical AI Agents are "connected via APIs",
  and the Data Hub offers "40+ pre-built connectors". None of it is publicly reachable, and none of
  it is documented - there is no token endpoint, no header name, no scope list, no example request.
